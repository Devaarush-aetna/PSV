Official License Verification

In order to request an official license verification to be sent to another state's board, please complete the steps below

  • submit the $23 payment here.
  • Send an email containing the following to socialwork1@wvsocialworkboard.org 
    • Receipt of payment
    • Name
    • License Number
    • Where the verification is to be sent (physical address or email)
    • Any form that is to be included with the verification

The above process also includes VOE forms for the WV Secretary of State. 

Please allow 15 business days for verification to be complete.
