Public License Individual Search

Under Idaho law, a license generally means any "license, certificate, certification, registration, permit, or other authorization of any person to practice a profession or occupation." Idaho Code section 67-9403(3).
Individual Search should be used when searching for a specific individual's license. Search results display more data about the license than is available in the list search, such as license history, discipline details, etc. Individual Search results are real-time.

License Types (optional)

Filter your search by optionally specifying the board and type of license.
You must enter either the license number or name for the licensee you are searching for.
