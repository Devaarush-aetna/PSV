License Verification
To verify that a license is active, use the fields below to perform a search by selecting the search criteria (Individual or Business) and then entering either the licensee’s first name, licensee’s last name, or business name, the license number, or select the license status. Then press the “Search” button . To clear your search, press the ”Clear” button.
When searching by licensee’s last name, remember to use only the last name or a part of the last name. For example, to search for ”John Doe,” using “Doe” or ”Do“ will return John Doe. Using “Does” or “John Doe” however, will not return a match.
If using alias name, please enter the full alias name in First OR Last Name fields.
