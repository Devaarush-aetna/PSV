    What Happened?

The above error indicates that the URL, which you have attempted to access, cannot be resolved by DNS.

URL: https://kybopp.aithent.com/

    How Did It Happen?

This error can have several causes:

  • The URL is spelled wrong or has a typographical error.
  • The hyperlink that you have chosen on a referring web page is spelled wrong or has a typographical error.
  • The URL is not currently available via the Internet Domain Name Service (DNS)

    What Does This Error Mean?

The Aetna Proxy Server has received your browser's request and tried to resolve the URL's domain name to an IP Address with the Domain Name Server.  The Domain Name Server has responded that it currently does not have an IP Address associated with that domain name.

    How To Correct The Error!

Of course this depends on the actual cause, as noted above there can be several!

  • If you typed the URL on your browser's address line then:
    1. Check the URL for typing or spelling errors.
  • If you feel the URL is correct as entered then:
    1. Contact the web site owner.
  • If you clicked a link from another web site then:
    1. Contact the referring web site owner to validate the link.
    2. Contact the target web site owner.
